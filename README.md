# CareerAI 🚀

CareerAI is an AI-powered full-stack SaaS platform built using the MERN stack. It helps users improve their career journey through resume analysis, job matching, interview preparation, and AI-powered resume building.

## Features

* 🔐 Authentication (Manual Login + Google OAuth)
* 📄 AI Resume Analysis
* 🎯 Job Matching
* 💼 Interview Preparation
* 📝 AI Resume Builder
* 💳 Subscription Payments
* 👤 Account Management
* 📱 Responsive UI

---

🛠️ Tech Stack

### Frontend

* React
* TypeScript
* Tailwind CSS

### Backend

* Node.js
* Express.js

### Database

* MongoDB

### APIs & Services

* Google Gemini API
* Razorpay
* Google OAuth

## Installation

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Backend Setup

```bash
cd backend
npm install
npm start
```

---

## Environment Variables

Create a `.env` file in backend:

```env
MONGODB_URI=
JWT_SECRET=
GEMINI_API_KEY=
RAZORPAY_KEY_ID=
RAZORPAY_SECRET=
GOOGLE_CLIENT_ID=
```
